# # 《野蛮时代》游戏用户付费行为分析

## 项目背景

基于游戏玩家注册后前7日的行为数据，通过 MySQL + Power BI 建立用户/收入/对战三个维度的指标体系，并在课程要求的基础看板之外，额外验证**早期游戏投入强度与后续付费转化之间的关系**，为运营的付费引导策略提供数据支持。

## 数据说明

- 数据来源：课程提供的游戏行为数据集（因版权原因，原始数据文件不公开）
- 数据规模：约 106 万条用户记录
- 数据维度：注册信息、资源获取/消耗（木头/石头/象牙/肉/魔法）、建筑等级、科研等级、部队招募/损失、PVP/PVE 战斗次数、在线时长、付费行为（7日付费金额、45日预测付费金额）

## 分析方法

1. **数据建模**：用 MySQL 建表导入原始数据（见 [`CREATE_TABLE.sql`](./CREATE_TABLE.sql)）
2. **指标构造**：用 SQL 聚合 15 项建筑等级字段，构建"发展度评分"指标，衡量玩家早期游戏发展投入程度（见 [`analysis_queries.sql`](./analysis_queries.sql)）
3. **可视化看板**：在 Power BI 中搭建总体、用户分析、收入分析、对战分析四个页面的指标看板
4. **相关性验证**：按发展度评分分组，对比各组的付费表现，并计算整体线性相关系数做交叉检验

## 关键发现

| 发展度分组 | 用户数 | 平均7日付费 | 平均45日预测付费 | 付费用户占比 |
|---|---|---|---|---|
| 无建筑发展（0分） | 34万 | ¥0.00 | ¥0.02 | 0.06% |
| 低度发展（1-5分） | 21万 | ¥0.00 | ¥0.02 | 0.03% |
| 中度发展（6-16分） | 26万 | ¥0.00 | ¥0.01 | 0.11% |
| **高度发展（17分以上）** | 26万 | **¥2.14** | **¥6.97** | **6.38%** |

- 发展度评分与45日预测付费额的整体线性相关系数仅为 **0.11**，看似关联较弱
- 但分组后发现，付费行为**高度集中在"高度发展"用户群体**——该组付费转化率（6.38%）是最低组（0.06%）的约 **106倍**，45日预测付费均值达到最低组的约 **348倍**
- 这说明发展度与付费之间存在**非线性的门槛效应**：低于一定投入水平的用户几乎不付费，一旦跨过门槛，付费概率急剧上升。整体相关系数因大量零发展度、零付费的沉默用户被拉低，无法反映这一真实模式

**业务建议**：针对中低发展度但仍保持活跃的用户，建议设置阶段性成长激励（如建筑加速道具、资源包），帮助其更快跨过付费转化门槛；同时可进一步分析高发展度用户的具体转化路径，识别可复用的引导策略。
